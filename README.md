# Cross-species cardiac aging — analysis code

**A conserved fibroblast-driven senescence niche organizes cardiac aging across mammals**

Single-nucleus RNA-seq, single-nucleus ATAC-seq and 10x Visium spatial
transcriptomics of young and aged **human, macaque and mouse** hearts,
identifying a conserved fibroblast state transition, spatially localised
senescence niches and a candidate **THBS1–CD36** communication axis.
